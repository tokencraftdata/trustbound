# Manuscript license

The MIT license in the repository root covers the TrustBound source code,
Lean models, scripts, tests, evidence files and technical documentation.
It does **not** cover the manuscript.

The manuscript (the LaTeX sources, figures and PDFs under `paper/`) remains
copyright of its authors. When it is posted to arXiv, it will be distributed
under the arXiv.org perpetual, non-exclusive license to distribute
(<https://arxiv.org/licenses/nonexclusive-distrib/1.0/license.html>). That
license lets the authors later publish the work elsewhere, for example in a
Springer LNCS proceedings volume, subject to that publisher's own agreement.

Third-party material keeps its own terms; for example, the `llncs.cls` class
file inside the arXiv source ZIP is Springer's.
