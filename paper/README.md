# Manuscript under review

`TrustBound_Draft.pdf` and `arxiv/` are the nine-page manuscript reviewed on
5 November 2026: **TrustBound: A Mechanized Case Study of Payment-Epoch
Completeness**. The author is reviewing this version. Repository framework
branding and the new explanatory diagrams do not change its scientific claims.

The PDF is intentionally marked as a preparation draft. Sole authorship is
confirmed; exact publication name/affiliation, category, arXiv eligibility and
release licenses remain pending. No arXiv submission has occurred.

The local typesetting check used Tectonic 0.17.0. From `arxiv/`:

```sh
tectonic --untrusted --keep-logs main.tex
```

The references are embedded in `references.tex`; no separate BibTeX run or
external figure file is needed for this preserved draft. The current repository
diagrams are in `../docs/diagrams/` for consideration in the next author revision.
